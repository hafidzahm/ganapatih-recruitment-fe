# Ganapatih-FE-Twitter App — README

---

## Langkah Instalasi Project

## 0) Prasyarat

- **Node.js ≥ 18** dan **npm ≥ 10**
- Port kosong: 5173 (App)

## 1) Clone & Install Dependencies

```bash
git clone ganapatih-recruitment-fe
cd ganapatih-recruitment-fe
npm install
```

## 2) Siapkan Environment

Salin contoh env:

```bash
.env.example .env
```

```
VITE_API_URL=YOURBACKENDURL
```

## 3) Jalankan Aplikasi

### Development

```bash
npm run dev
```

### Build & Start

```bash
npm run build
npm start
```

## Aplikasi ini dideploy oleh layanan Firebase.
